## 🚀 Featured Flagship Project

### 🏥 **MedConnect – Healthcare Appointment Management System**
*Full-stack enterprise healthcare application enabling patients to search doctors, view real-time schedules, and book appointments.*

- **Frontend:** Angular 17+, TypeScript, RxJS, HTML5, CSS3, Bootstrap 5.
- **Backend:** ASP.NET Core Web API, C#, Entity Framework Core, LINQ, JWT Authentication, Custom Middleware.
- **Database:** Microsoft SQL Server.
- **Key Modules:**
  - Dynamic doctor availability calendar & conflict avoidance booking engine.
  - Role-Based Access Control (RBAC) with JWT Bearer tokens for **Admin**, **Doctor**, and **Patient** roles.
  - Complete RESTful CRUD APIs for doctors, patients, appointments, and medical records.
  - Rigorously tested and documented using **Swagger** and **Postman**.

To run this portfolio locally:

```bash

npx serve .
# Or simply open index.html directly
```
